PERIS v8 — FEATURE AND SYSTEM REFACTOR

Apply the ZIP at your existing Peris repository root; replace files.
Keep your Git repository and environment configuration.

IMPORTANT: files moved, so extracting a ZIP alone leaves obsolete modules.
From the repository root run:

  node scripts/clean-legacy-paths.mjs
  npm install
  npm test
  npm run build

On Windows use npm.cmd if needed. The cleanup only deletes known unchanged
v5/v6/v7 source/art files. Personal edits are preserved and reported; move those
old files outside src, then merge their edits into the new feature modules.
The full-project ZIP is a clean tree and does not need cleanup if used fresh.

No database migration is required when upgrading the previous v7 release:
this refactor preserves SQL behavior, save keys and the v6 save format.
If you are still on v5/v6, run the entire supabase/UPGRADE_TO_V8.sql in Supabase
SQL Editor. Do not reset your world. Fresh install is for an empty DB only.

Commit and push in GitHub Desktop; your existing Vercel project deploys it.
ARCHITECTURE.md maps each gameplay system to its source files.
