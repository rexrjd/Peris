INSTALL
1. Open the project folder containing the main package.json and src folder.
2. Copy this ZIP's src folder into that project folder, merging folders and replacing matching files.
3. Keep all nine included source files, including the new rendering/three folder and CompatibilitySettlementScene.tsx.
4. Commit/push your changes to your connected repository and let Vercel redeploy, or build locally with npm run build.
