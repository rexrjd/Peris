PERIS — HOUSING, POPULATION & CITY OVERVIEW

INSTALL
Merge src/, supabase/, tests/, and package.json into your existing project, replacing matching files. This package includes the latest mage-tower and faction updates and applies to the existing city-building-slots project.

Shared worlds — apply ONE appropriate database upgrade BEFORE deploying:
- Previous faction/mage updates installed: supabase/UPGRADE_HOUSING_AND_POPULATION.sql
- City slots installed, mage update missing: supabase/UPGRADE_MAGE_TOWER.sql (includes factions and population)
- City slots missing: supabase/UPGRADE_CITY_SLOTS.sql (includes all these features)

Do not run FRESH_INSTALL scripts on an existing world. The upgrade preserves existing progress, faction, troops, spells and plots. It catches up legacy income and completed construction before starting population. Re-running the population migration preserves current population progress.

Then run npm run build and deploy through your usual GitHub/Vercel workflow. Solo games migrate automatically; SQL is only needed for shared worlds.

GAMEPLAY
- Cities begin with 30 residents and room for 40. Each main-building level adds 10 places.
- Housing is optional and repeatable. Each of its five levels adds 30 places, with five visual stages styled for all 11 factions.
- Residents grow by one per minute when housing and food allow it.
- Each resident consumes 0.12 food per minute. The top resource bar now shows net food after consumption.
- An exhausted food supply pauses growth. With a continuing food deficit, residents leave at one per minute until food balances or the city reaches 10 residents.
- Demolishing housing immediately reduces residents to the remaining capacity.
- Production workers are assigned automatically. Staffing shortages proportionally reduce building production bonuses. Base gathering remains 14 wood, 12 stone, 18 food and 3 gold per minute.
- Workers per building level: main building 4; lumberyard 6; quarry 6; farm 5; fishery 4.
- Production bonuses per fully staffed level: main +3 gold; lumberyard +8 wood; quarry +7 stone; farm +10 food; fishery +8 food.
- Growth, consumption and production continue consistently while offline.

INTERFACE
The city overview shows residents and capacity, growth, assigned/missing workers, staffing, gross/net food and consumption, resource storage and production. Expand its production details for worker demand by building. Its housing shortcut selects an available plot, or the main building when more plots are needed.

The building menu includes Housing. Building details show housing capacity and production worker demand. Warehouse and granary capacities are shown separately. The debug panel includes Fill housing with residents for instant population testing, subject to the existing shared-world debug setting.
