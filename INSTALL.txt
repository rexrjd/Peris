PERIS — FACTIONS & CITY DEBUG TOOLS

INSTALL
Merge src/, supabase/, tests/, and package.json into your existing project, replacing matching files. Apply after the previous city-building-slots update. This ZIP includes the latest mage-tower/spell files too.

Shared worlds: run supabase/UPGRADE_FACTIONS_AND_DEBUG.sql BEFORE deploying if the mage-tower database update is already installed. If the city-slots update is installed but the mage update is not, run the included UPGRADE_MAGE_TOWER.sql instead; it includes factions and debug tools. If neither update is installed, use UPGRADE_CITY_SLOTS.sql; it includes all three features. Run one applicable upgrade. Existing cities, resources, armies and progress are preserved. Do not run a FRESH_INSTALL script on an existing world.

Then run npm run build and push/redeploy through your usual GitHub/Vercel flow. Solo saves work automatically with no SQL step.

HOW TO USE
In City, select a building. The sidebar contains CITY FACTION: choose a culture or click Next faction to switch immediately. The choice persists in solo saves and shared worlds. City architecture, walls, landscape, walking villagers and world-map city miniatures follow the faction. Existing building levels, resources and spell research are retained when changing faction.

Expand Debug tools in the sidebar:
- +1,000 resources adds 1,000 of each resource, up to the appropriate storage limit.
- Fill storage instantly fills materials and food to their separate capacities.
- Finish construction instantly completes the current building order.
- Instant level sets the selected building's level: 0–5, or 0–10 for the mage tower.
- Demolish clears a selected plot, or resets a fixed building to level zero. Its pending upgrade is cancelled. Demolition gives no refund.

Lowering the main building removes plots beyond its new limit and their pending orders. The external river fishery remains available. Destroying a mage tower also clears that city's spell research. Resources clamp to the remaining storage capacity. Debug mutations are unavailable during an active battle; faction switching remains available.

Shared-world debug tools operate only on the signed-in player's own city. To hide/disable instant debug tools later, run:
update public.peris_debug_config set enabled=false where id=true;
To restore them, set enabled=true. Faction selection remains available either way.
