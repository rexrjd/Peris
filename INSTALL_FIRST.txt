PERIS v7 — THE SIX STANDARDS — LATEST CHANGES

1. Extract this ZIP into the root of your existing Peris repository, beside
   package.json. Replace files. Keep your existing Git repository.

2. Supabase > SQL Editor: run the ENTIRE supabase/UPGRADE_TO_V7.sql file.
   This upgrades existing v5/v6 worlds and preserves players and accounts.
   Do not use a reset or a fresh-install script for an existing world.

3. Local test: npm install, then npm run dev (npm.cmd on Windows).
   Requires Node 20.19 or later.

4. GitHub Desktop: commit the changes and Push origin.
   Your existing connected Vercel project deploys the commit.

Solo saves retain the v6 format. Hosted saves on the same browser origin resume.
Use Settings > Campaign Saves to export/import saves between browsers or files.
See README.md for features and controls; UPDATE_CONTENTS.txt lists patch files.
