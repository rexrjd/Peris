EMPIRE AND HEROES UPDATE — START HERE

Replace the included files at matching repository paths.
For an existing Supabase world, run supabase/UPGRADE_TO_V10.sql once in the SQL editor.
For an empty Supabase database only, use supabase/FRESH_INSTALL_V10.sql.
Do not use fresh installation on an existing world. Do not run older feature-only
upgrade scripts after V10; use the complete V10 upgrade for current gameplay.

Existing cities, armies, troops, accounts, queues and solo saves are retained.
Menu > Cities & expansion opens culture, settlers and founding.
Army opens commanders, artifacts, army selection and troop transfers.
Read docs/empire-and-heroes.md for the rules and a fast local test flow.

Run npm install and npm run build. npm run test:empire-db verifies the database
rules in an isolated local PostgreSQL instance without contacting your server.

If upgrading from an older pre-refactor source tree, run
node scripts/clean-legacy-paths.mjs from the repository root first. It removes
only recognized unchanged legacy files and preserves personal edits.
Use npm.cmd on Windows if PowerShell blocks npm scripts.
