PERIS COMBINED GAME UPDATE — START HERE

There is one game. Frontier mechanics share existing Peris accounts, villages,
legions, resources and reports. No extra Node game server is required.
Review and run supabase/UPGRADE_TO_V17.sql for an EXISTING database before
deploying this frontend. Use FRESH_INSTALL_V17.sql only for an EMPTY project.
Offline processing additionally requires pg_cron and ENABLE_GAME_WORKER.sql.
Publishing source code does not install these production database updates.

Rally Point combines owned stations, incoming/outgoing troops, farm lists and
grouped reports. Recruitment also opens in Barracks, Stables and Workshop
building windows. All marches review troop allocations and have a 30-second
cancellation window. Lost responses can retry the original order safely after
reload using private command receipts. Read docs/frontier-wars.md for details.

The notes below describe the earlier V12 release. Use V17 for current gameplay.

Replace the included files at matching repository paths.
For an existing Supabase world, run the corrected supabase/UPGRADE_TO_V12.sql
from this ZIP in the SQL editor. It fixes upgrades with existing housing rows.
For an empty Supabase database only, use supabase/FRESH_INSTALL_V12.sql.
Do not use fresh installation on an existing world. Do not run older feature-only
upgrade scripts after V12; use the complete V12 upgrade for current gameplay.

Existing cities, armies, troops, accounts, queues and solo saves are retained.
Menu > Cities & expansion opens culture, settlers and founding.
Army opens commanders, artifacts, army selection and troop transfers.
Read docs/empire-and-heroes.md for the rules and a fast local test flow.

Battles start automatically. Both armies use AI, including spells and rallies.
The latest 3D faction graphics and the 2D fallback are supported.
Read docs/automatic-battles-compatibility.md for the tested main commit and checks.

Run npm ci and npm run build. npm run test:empire-db verifies the database
rules in an isolated local PostgreSQL instance without contacting your server.

If upgrading from an older pre-refactor source tree, run
node scripts/clean-legacy-paths.mjs from the repository root first. It removes
only recognized unchanged legacy files and preserves personal edits.
Use npm.cmd on Windows if PowerShell blocks npm scripts.
