# Editable source assets

Keep Blender files and editable textures here. These sources use Git LFS.
Run `git lfs install --local` before committing source assets. No existing
repository history is migrated by this setup.

Export game-ready models to `public/models/`, register them in
`assets/manifest.json`, and follow `docs/GRAPHICS_PIPELINE.md`.
Do not add downloaded assets until their license is recorded.
